### 5. **API 集成**

所有管理页面都集成了对应的 API 端点：

```
GET    /api/messages              - 获取留言列表
DELETE /api/messages/{id}         - 删除留言
PUT    /api/messages/{id}         - 更新留言

GET    /api/projects              - 获取项目列表
DELETE /api/projects/{id}         - 删除项目

GET    /api/music                 - 获取音乐列表
DELETE /api/music/{id}            - 删除音乐
PUT    /api/music/{id}            - 更新音乐

GET    /api/movies                - 获取电影列表
POST   /api/movies                - 创建电影
DELETE /api/movies/{id}           - 删除电影

GET    /api/travel/cities         - 获取城市列表
DELETE /api/travel/cities/{id}    - 删除城市
GET    /api/travel/footprints     - 获取足迹列表
DELETE /api/travel/footprints/{id}- 删除足迹

GET    /api/siteConfig            - 获取网站配置
PUT    /api/siteConfig/{id}       - 更新网站配置

PUT    /api/auth/change-password  - 修改密码
```
